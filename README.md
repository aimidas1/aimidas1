# AI Midas Football Data — Dados Gratuitos para Research

## Descrição

Este repositório contém **dados gratuitos de futebol**, disponíveis em formatos **CSV** e **Excel**, organizados para análise, modelagem, leitura estatística e research.

O objetivo é simples: transformar dados brutos de futebol em uma base utilizável para quem quer estudar ligas, equipes, jogadores, odds, performance e métricas avançadas com mais estrutura.

---

## 1. Dados de mais de 30 ligas

A base inclui dados de **mais de 30 ligas**, com estatísticas tanto da liga como das equipes.

Estão disponíveis informações sobre:

- jogos da liga;
- rodadas;
- estatísticas médias das equipes;
- métricas ofensivas;
- métricas defensivas;
- corners;
- cartões;
- finalizações;
- posse;
- xG;
- odds;
- dados pré-jogo;
- dados de primeiro e segundo tempo.

## 2. Estatísticas históricas de 2016 a 2024

O repositório também inclui estatísticas passadas desde 2016 até 2024 para mais de 30 ligas.

Esses dados permitem analisar:

evolução histórica das ligas;
desempenho por temporada;
padrões por rodada;
médias dos clubes;
comportamento estatístico ao longo do tempo.

A lógica não é olhar apenas para resultado.
É criar base para leitura histórica, comparação e contexto.

## 3. Estatísticas históricas dos jogadores

Além dos dados de ligas e equipes, também estão disponíveis estatísticas passadas dos jogadores.

Esses dados podem ser usados para análises individuais, comparação de performance e estudos de evolução por atleta.

## 4. Jogos do dia

O repositório inclui também dados sobre jogos do dia, com informação sobre:

odds;
estatísticas gerais;
contexto estatístico pré-jogo.

Esta camada é útil para quem quer acompanhar o calendário atual com dados organizados e prontos para análise.

Nota final

Este repositório não é sobre palpite.
É sobre dados, contexto e leitura.

A proposta é oferecer uma base gratuita para quem quer estudar futebol com mais profundidade, usando estatísticas, histórico, odds e métricas avançadas como matéria-prima para research.
